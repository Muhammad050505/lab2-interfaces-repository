# Лабораторная работа №2

Тема: Интерфейсы. Репозиторий. JSON.

## Часть 1. Интерфейсы

Реализованы задания 1–4:
- IMovable, IDrawable
- IShare, I3DShare
- ISP: IPrinter, IScanner, IFax
- IPayable, ILogger

### Контрольные вопросы
1. Интерфейс — контракт, описывающий набор методов/свойств без реализации.
2. Создать объект интерфейса напрямую нельзя, только через класс-реализацию.
3. Полиморфизм интерфейсов даёт единый способ работы с разными классами.
4. Класс реализует много интерфейсов, но наследует один абстрактный класс; интерфейс не хранит состояние.
5. ISP — клиенты не должны зависеть от методов, которые не используют.
6. Примеры: USB, розетка, оплата картой/наличными, водительские права.
